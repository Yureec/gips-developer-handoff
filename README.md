# GIPS — инвестиционное пространство

React/TypeScript-приложение инвестиционного портала для изучения архитектуры, интерфейсных сценариев и переиспользования компонентов. Включает рабочие пространства Mass, Only, руководителя, инвестиционного консультанта и партнёра; продукты, обучение, конкурсы, показатели и каталог наград.

## Исходный HTML-прототип

[GIPS-prototype-v20260910-7.html](prototypes/GIPS-prototype-v20260910-7.html) — исходная версия от 10 сентября 2026 года, сохранённая без изменений для изучения и сравнения с React-приложением. Скачайте файл через кнопку **Raw / Download** на GitHub и откройте его в браузере. Это исторический прототип; актуальный код приложения находится в `src/`.

## Быстрый запуск

Требуются Node.js 26 и npm 11. Проверенная версия Node указана в `.nvmrc`.

```sh
npm ci
npm run dev
```

Vite выведет локальный адрес приложения. Для сборки:

```sh
npm run typecheck
npm run build
npm run preview
```

Автономный файл с встроенными ресурсами:

```sh
npm run build:standalone
```

Результат — `release/GIPS.html`, который можно открыть с диска. Сборка выполняется из исходников; готовые сборки не хранятся в Git.

## Технологии

React 18, TypeScript, Vite, Alfa Core Components, Alfa icons, Playwright и axe. Версии зависимостей закреплены в `package-lock.json`. Для работы приложения не нужны ключи API или серверная база данных.

## Текущее поведение

Данные берутся из локальных источников. Переключатель ролей управляет представлением и не является авторизацией. Некоторые разделы пока представлены заготовками. Оформление наград и сохранение отзыва о визите требуют реализации хранения результата; текущие сообщения интерфейса не подтверждают внешнюю операцию. Поиск и возврат в каталог также требуют дальнейшей проработки. При подключении реальных систем эти границы нужно реализовать в контрактах команд и источников данных.

Рабочие размеры интерфейса: 1920×1080 и 1366×768. Наличие визуального эталона означает сравнение с сохранённым состоянием приложения, а не полное соответствие дизайн-макету.
