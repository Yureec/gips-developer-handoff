# Сторонние компоненты и материалы

Приложение использует React, Vite, TypeScript, Alfa Core Components и Alfa icons через npm. Исходные версии и дерево зависимостей закреплены в `package-lock.json`; лицензии пакетов доступны в установленных пакетах. Уведомление MIT для Core Components сохранено в `licenses/core-components-MIT.txt`.

Названия продуктов, бренды, изображения, документы и шрифты не становятся автоматически доступными по MIT-лицензии зависимостей. Общая открытая лицензия на все материалы этого репозитория не назначена. Для использования вне согласованного проекта отдельно определите допустимость использования соответствующих ресурсов и замените их при необходимости.

Репозиторий не содержит исходных архивов сторонних библиотек, кэша npm или полной документации Storybook. Нужные пакеты устанавливаются обычной командой `npm ci`.
