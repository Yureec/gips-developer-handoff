# Проверки и границы реализации

Проверка этой поставки 28 сентября 2026: чистая установка через `npm ci`, обычная и автономная сборки успешны. Совместный прогон `route-ids.spec.ts`, `integration.spec.ts` и `standalone.spec.ts` — **58 passed** на двух ширинах. Это целевая проверка поставки, а не утверждение о прохождении всего исторического набора.

Проверки запускаются локально через Playwright на Chromium с размерами 1920×1080 и 1366×768. Эталоны чувствительны к платформе и версии браузера; существующие снимки создавались на macOS.

`npm run test:routes` проверяет валидные, неизвестные, пустые и унаследованные имена ID, восстановление страницы и историю браузера. `test:integration` проверяет основные сценарии и геометрию. `test:standalone` собирает и проверяет автономный файл. `test:e2e` собирает обе версии и запускает весь набор.

Текущий полный исторический набор не является зелёным: остаются ожидания прежнего интерфейса обучения, расхождения визуальных эталонов игр/профиля/материалов и проверка контраста страницы показателей. Эти проверки сохранены; обновлять эталоны следует только после просмотра фактического результата. Старые проверки учебного адаптера выполняются на отдельных стендах.

Известные границы, которые нужно учитывать при переносе:

- Состояния оформления награды и отзыва о визите не подтверждаются сохранённой операцией.
- Некоторые результаты поиска ведут в общий раздел; контекст каталога при возврате из продукта может сбрасываться.
- Страница показателей требует явного подключения собственного CSS.
- API, серверная авторизация, серверное хранение и согласование неизвестных бизнес-правил не реализованы.
- Старые тесты могут записывать диагностические изображения в `docs/learning/`; эта папка исключена из Git поставки.

Эти ограничения не нужно принимать за готовые контракты будущей системы. Тесты нового поведения следует добавлять вместе с соответствующей реализацией.
