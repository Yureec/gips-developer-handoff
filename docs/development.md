# Архитектура и переиспользование

## Поток данных

`main.tsx` подключает React, конфигурацию Core Components и общие стили. `App.tsx` читает роль и раздел из query-параметров, получает представления из `portalDataProvider` и выбирает страницу. Часть переходов использует History API, часть — обычные ссылки. При адаптации к маршрутизатору целевого проекта нужно сохранить параметры сущности и поведение возврата.

`src/data/provider.ts` описывает контракт текущего синхронного источника. `portalDataProvider.ts` содержит его локальную реализацию. Это не HTTP-клиент. Для API потребуется граница преобразования данных, состояния загрузки/ошибки и отдельные команды записи. Ролевой параметр URL нельзя использовать как проверку доступа.

`src/domain/metrics.ts` различает выполнение плана, прогноз и неизвестные значения. `src/domain/focus.ts` считает темп с заданным рабочим календарём. Не заменяйте отсутствующие правила или значения нулём; источник должен задавать период, охват и семантику показателя.

## Перенос виджета

1. Найдите его компонент в `src/components/widgets/` и тип входных данных.
2. Перенесите используемые примитивы, импорты Alfa и иконки.
3. Найдите классы компонента в общем и модульном CSS; перенесите необходимые правила вместе с токенами.
4. Передайте данные из источника целевого приложения вместо прямого импорта локального singleton.
5. Проверьте нормальное, пустое и недоступное состояние, навигацию с клавиатуры и обе desktop-ширины.

Компоненты пока не выделены в независимый npm-пакет. Копирование одного TSX без CSS и ассетов может изменить внешний вид. Есть страницы с данными непосредственно в разметке; их следует адаптировать к контрактам целевой системы.

## Обучение

Текущий интерфейс построен модулями `EducationWorkspace`, `EducationOverview`, `EducationCatalogs`, `EducationDetail`, `EducationResources`, `EducationShared` и `EducationData`. Прогресс в этом интерфейсе происходит из локального среза, ссылки открывают учебную платформу; регистрация событий хранится в браузере.

`LearningProvider`, `DailyInvest`, `AssignmentDetails` и `Events` сохраняют отдельные контракты будущего источника и проверяются изолированными стендами. Их нельзя считать уже подключённым источником текущих `Education*`. Перед интеграцией выберите единый путь данных и перенесите обработку подтверждённых результатов.

## Маршруты

Примеры: `?role=mass&section=home`, `?role=mass&section=focus&product=nsj`, `?role=mass&section=scenario&scenario=conversation-challenge`, `?role=mass&section=public-profile&person=dmitry`.

Сценарии и публичные профили проверяют собственные ключи реестра. Явно неизвестный или пустой ID показывает недоступность; отсутствие необязательного параметра сохраняет существующий маршрут по умолчанию. Новые сущности должны следовать тому же принципу и не подменять неизвестный ID произвольной записью.
