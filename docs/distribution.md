# Состав поставки

Дата подготовки: 28 сентября 2026. Версия исходного кода: `679c8ffb`.

Репозиторий содержит самостоятельный снимок приложения с новой историей: исходники, текущие изображения, шесть PDF, три файла шрифта, конфигурации, lockfile, тесты и документацию разработчика. Готовый автономный HTML собирается командой `npm run build:standalone`.

Особенности упаковки:

- Шрифты расположены в `src/assets/fonts/`, путь подключения в CSS обновлён.
- Ссылка-приглашение в канал и адреса внутренней CRM заменены на адреса `example.org`. При подключении системы задайте собственные адреса.
- Удалены команды, зависевшие от архивов Storybook, локального npm-кэша и исходного HTML-референса. Для запуска используется обычная установка зависимостей.
- Сохранены тесты и их эталоны; диагностические результаты и готовые сборки исключены из Git.

Для обновления используйте новую отобранную версию исходников с проверкой состава и запуском тестов. Не заменяйте историю этого репозитория историей другого проекта.
